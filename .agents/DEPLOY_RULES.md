## 1. Управление процессом бота на сервере

### Бот управляется через PM2 (НЕ через nohup/pkill!)

- **Процесс-менеджер:** PM2 v7 (`God Daemon`)
- **Имя процесса:** `pulse-bot`
- **Сервер:** `192.109.206.42`

### Команды управления (ЕДИНСТВЕННО ПРАВИЛЬНЫЕ):
```bash
# Перезапустить бота после деплоя
pm2 restart pulse-bot

# Посмотреть статус
pm2 list

# Посмотреть логи (ошибки и вывод)
pm2 logs pulse-bot --lines 50 --nostream

# Остановить бота
pm2 stop pulse-bot

# Запустить бота
pm2 start pulse-bot
```

### ЗАПРЕЩЕНО:
- ❌ `pkill -f 'pulse.bot.main'` — PM2 мгновенно перезапустит процесс.
- ❌ `nohup .venv/bin/python -m pulse.bot.main &` — создаст дубль, конфликтующий с PM2.
- ❌ `kill -9 <pid>` — PM2 немедленно поднимет новый процесс.

### Другие сервисы (через systemd):
- `pulse-dashboard.service` — диагностический дашборд.
- `pulse-site.service` — витрина отрывного календаря (порт 8081).

## 2. Обязательная проверка перед деплоем

### Чек-лист (выполнять КАЖДЫЙ раз):

1. **Синтаксис (быстрая проверка):**
   ```bash
   .venv/bin/python -m py_compile src/pulse/bot/handlers/admin.py
   ```

2. **Runtime-импорт (ОБЯЗАТЕЛЬНО! py_compile НЕ ловит NameError):**
   ```bash
   .venv/bin/python -c "import pulse.bot.handlers.admin; print('OK')"
   .venv/bin/python -c "import pulse.bot.main; print('OK')"
   ```
   > ⚠️ `py_compile` проверяет ТОЛЬКО синтаксис. Пропущенный `from typing import Any`
   > или любой другой runtime-импорт НЕ будет обнаружен через `py_compile`.

3. **Деплой на сервер:**
   ```bash
   ssh root@192.109.206.42 "cd /var/www/pulse && git pull && pm2 restart pulse-bot"
   ```

4. **Проверка логов PM2 после деплоя (ОБЯЗАТЕЛЬНО!):**
   ```bash
   ssh root@192.109.206.42 "pm2 logs pulse-bot --lines 10 --nostream"
   ```
   Убедиться, что в `error.log` нет свежих трейсбеков.

5. **Функциональная проверка:**
   Отправить боту `/start` в Telegram и убедиться, что он ответил.

## 3. Типичные ошибки (выученные уроки)

### Урок 1: NameError из-за пропущенного импорта (2026-08-08)
- **Что произошло:** В `admin.py` использовался `dict[str, Any]`, но `from typing import Any` не был добавлен.
- **Почему не поймали:** `py_compile` проверяет только синтаксис, `Any` — допустимое имя.
- **PM2 перезапустил бота 162 раза**, каждый раз получая тот же краш.
- **Решение:** Всегда делать runtime-импорт проверку (п.2 чек-листа).

### Урок 2: Два экземпляра бота (2026-08-08)
- **Что произошло:** `nohup ... &` создал второй процесс бота параллельно PM2.
- **Последствия:** Два polling-процесса делили обновления Telegram, сообщения терялись.
- **Решение:** Использовать ТОЛЬКО `pm2 restart pulse-bot`.

### Урок 3: Middleware блокирует админа после 18:00 МСК
- **Что произошло:** `RateLimitMiddleware` блокирует ВСЕ сообщения без текста (фото) и нестандартные команды после 18:00 МСК.
- **Решение:** В middleware добавлена проверка `is_admin()` — админ обходит все ограничения 24/7.

### Урок 4: int vs str сравнение ADMIN_CHAT_ID
- **Что произошло:** `.env` хранит ADMIN_CHAT_ID как строку, Telegram передаёт user.id как int. Сравнение `1013912602 == "1013912602"` → `False`.
- **Решение:** В `is_admin()` оба значения приводятся к `int()`.
