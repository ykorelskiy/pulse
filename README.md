# Pulse — Ежедневный генеративный дайджест-плакат (Assisted Mode)

Проект **Pulse** — автоматизированная платформа для создания и дистрибуции ежедневных иллюстраций-постеров в стиле плакатной сатиры 70–80-х годов.

---

## 🎨 Как работает Assisted Mode

После проведения серии бенчмарков (Спринт 3) принята гибридная архитектура **Assisted Mode** (подробнее в [ADR 001](docs/adr/001-assisted-mode.md)):

```
[RSS-ленты] ──> [Сборщик новостей] ──┐
                                     ├──> [Формирование брифа] ──> [Бот автору]
[Бот сбора] ──> [Слова читателей] ───┘                                   │
                                                                         ▼
                                                             [Автор рисует в ChatGPT]
                                                                         │
                                                                         ▼
[Канал Telegram] <── [Публикатор] <── [Cloudflare R2] <──────── [Загрузка в бот]
```

1. **Автоматика:** Собирает новости, агрегирует слова от читателей бота и готовит 4-строчный бриф в 18:00 МСК.
2. **Автор:** Генерирует постер в ChatGPT, при необходимости правит его и загружает в бот.
3. **Автоматика:** Принимает картинку, оптимизирует её (Pillow), загружает в R2, выкладывает в Telegram-канал, заносит в архив и запускает конкурс разгадок.

## 🚀 Быстрый старт за 10 минут

### 1. Требования
- Python 3.12+
- Supabase account (free tier)
- Cloudflare R2 bucket

### 2. Локальное окружение
```bash
# Клонирование и виртуальное окружение
git clone https://github.com/your-org/pulse.git
cd pulse
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -e ".[dev]"

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env и укажите ваши ключи Supabase / R2 / Telegram

# Проверка конфигурации
python -m pulse.config --check
```

## 🗄️ Применение миграций в Supabase

1. Перейдите в **Supabase Dashboard -> SQL Editor**.
2. Откройте файл [`migrations/001_init.sql`](migrations/001_init.sql) и скопируйте его содержимое.
3. Нажмите **Run** для создания всех 10 таблиц и индексов.
