# ADR 001: Переход на гибридный режим генерации (Assisted Mode)

* **Дата:** 2026-08-07
* **Статус:** Принято
* **Автор:** Antigravity / Команда Pulse

---

## Контекст

Изначальная гипотеза проекта «Пульс» предполагала полностью автономный цикл генерации ежедневного дайджеста-плаката:
1. Агрегация новостей и слов пользователей.
2. Сборка промпта через LLM.
3. Автоматическая генерация картинки через Image API (Nano Banana Pro / Gemini / GPT-Image).
4. Автоматический QA-контроль (OCR gate).
5. Публикация в канал Telegram.

В ходе проведенного эксперимента (Спринт 3, 50 генераций на 5 брифах) выяснилось, что текущие модели Image API не способны автономно выдавать необходимую авторскую плотность деталей, удерживать узнаваемость персонажей и безупречно рендерить длинные кириллические тексты без искажений. При этом ручная генерация автором через ChatGPT по готовому короткому брифу даёт результат отличного качества.

---

## Рассмотренные варианты

### Вариант 1: Полная автоматизация (Full Auto Mode)
* **Плюсы:** Нулевые трудозатраты автора на ежедневные выпуски.
* **Минусы:** Высокий процент брака, потери в качестве и стиле, риск размытия бренда и потери аудитории.

### Вариант 2: Гибридный режим (Assisted Mode) — Выбранное решение
* **Плюсы:** Максимальное визуальное качество и авторская уникальность постеров при автоматизации 90% бэкенд-рутины (сбор новостей, темы дня, сбор слов читателей, подготовка короткого брифа, механика разгадок, архив и прием заказов).
* **Минусы:** Требуется ежедневное ручное действие автора (сгенерировать изображение в ChatGPT по брифу и загрузить его в бота).

---

## Решение

Принять **Assisted Mode** как базовую архитектуру проекта Pulse.

### Схема работы Assisted Mode:
1. **Бэкенд (автомат):** Каждый день система собирает новости, агрегирует слова читателей, формирует бриф для автора.
2. **Автор (ручная фаза):** Автор получает бриф в Telegram-бот, генерирует изображение в ChatGPT, при необходимости вносит авторские поправки и загружает готовый постер обратно в бот.
3. **Бэкенд (автомат):** Бот принимает постер, оптимизирует его, загружает в хранилище R2, публикует в Telegram-канал, открывает игру разгадок в группе и заносит постер в архив.

---

## Последствия

- **Архитектура:** Модули M4 (Promptsmith) и M5 (QA-Gate) упрощаются до модуля `Briefsmith`, который генерирует лаконичный и понятный бриф для автора вместо сложного инженерного промпта под Image API.
- **Надёжность:** Полностью исключаются ошибки кириллицы и сбои Image API при публикации.
- **Время автора:** Затраты времени автора ограничиваются 3–5 минутами в день.

---

## Критерии пересмотра (Re-evaluation Criteria)

Решение о переходе к Full Auto Mode может быть пересмотрено при выполнении условий:
1. Достижение качественными моделями Image API 100% точности рендеринга кириллических текстов.
2. Появление нативных механизмов детерминированного сохранения персонажей (Character Consistency).
3. Прохождение бенчмарка (`docs/BENCHMARK.md`) с интегральной оценкой узнаваемости и стиля `style_score ≥ 8.5` на 10 последовательных генерациях.
