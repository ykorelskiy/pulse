# Итоги эксперимента Sprint 3 — Автоматическая генерация изображений

**Дата:** 2026-08-07  
**Статус:** ❌ Отклонено (API-генерация не принята для продакшена)  
**Решение:** Переход на **Assisted Mode** (ручная генерация иллюстраций автором через ChatGPT + полная автоматизация бэкенда и дистрибуции).

---

## 1. Что проверялось и как

- **Цель:** Проверить возможность полностью автоматической автономной генерации иллюстраций-постеров в фирменном стиле канала через image API (`gemini-3-pro-image-preview` / `Nano Banana Pro`).
- **Методология:**
  - Создана единая база требований `STYLE_BIBLE.md`.
  - Порождены синхронные конфиги (`style_block.txt`, `characters.yaml`, `limits.yaml`, `checklist.yaml`, `anti_patterns.yaml`, `criteria.yaml`).
  - Проведено 50 тестовых прогонов на 5 тематических брифах («Техно-сатира», «Новостная аллегория», «Профпраздник», «День рождения», «Бытовой абсурд»).
- **Стоимость эксперимента:** $0.00 (прогоны в рамках лимитов API).

---

## 2. Вывод и причины отказа от автоматической генерации

Автоматическая генерация изображений через существующие image API **не достигает качественной планки автора** и отклонена.

### Причины по пунктам:
1. **Недостаточная плотность деталей:** Модели опускают мелкие нюансы, пасхалки и бирки, снижая рассматриваемость постера.
2. **Потеря консистентности персонажей:** Сквозной маскот «ПУЛЬС» и животные-комментаторы (Кот, Чайка, Пёс, Инспектор) меняют визуальный образ от генерации к генерации.
3. **Ошибки в кириллице:** Несмотря на прогресс в генерации текста, кириллические надписи периодически содержат искажения букв, артефакты или неточные переносы.
4. **Отсутствие «авторских находок»:** ИИ выдаёт усреднённую композицию, упуская тонкий юмор, двусмысленные детали и атмосферные мелкие предметы.

> **Сравнение:** Ручная генерация автором через ChatGPT по краткому брифу из 4 предложений даёт визуальный и смысловой результат на порядок выше.

## 3. Что сохранено для будущего

В архиве сохранены все наработки эксперимента для дальнейшего использования:
- `docs/STYLE_BIBLE.md` — источник правды по стилю и персонажам.
- `config/briefs.yaml` — 5 эталонных брифов и текстовые формулировки.
- `config/` — машиночитаемые лимиты, анти-паттерны и чек-листы.
- `assets/references/` — эталонные графические референсы («Наташа», «Кораблестроитель», «ВМФ»).
- `check_sync.py`, `generate.py`, `evaluate.py`, `contact_sheet.py` — инфраструктура тестирования генерации.

## 4. Условия возврата к автоматизации

Пересмотр решения о ручной генерации возможен при выполнении следующих критериев:
1. Появление новых моделей image API с поддержкой 100% пиксельно-точной кириллицы.
2. Появление генераторов с детерминированным запеканием референсных персонажей (Character Consistency Framework).
3. Прохождение бенчмарка (`docs/BENCHMARK.md`) с оценкой узнаваемости и стиля `style_score ≥ 8.5` на серии из 10 постеров подряд.
